# Katabasis — 世界観バイブル / 台本

「Katabasis（カタバシス＝冥界下り）」の物語設定と台本の確定版。
実装テキストは [`game/story/index.ts`](../game/story/index.ts) に集約する（本書＝原典、コード＝実データ）。

## 1. 世界観

- 地上の辺境に、小さな **拠点の村** がある。その傍らには地底へ続く
  **深淵（Abyss）への唯一の入口** が口を開けている。
- かつて深淵の底から、異形＝ **「淀み」に蝕まれた者** が這い上がり、地上を侵した。
  多くの村と人が呑まれた。
- 生き残りは入口を **塞ぐのではなく、見張る** ことを選んだ。塞げば淀みは別の地から
  溢れ出すという言い伝えがあるためだ。そこで彼らは、定期的に深淵を **下って淀みを鎮める**
  ための村を築いた。

## 2. 主人公

- 深淵を下る **探索者（descender）**。
- **動機**: 主人公の故郷もまた、淀みに呑まれて失われた。奪われたものへ決着をつけるため、
  拠点の村を訪れ、深淵の最深部＝淀みの源を断つべく下降する。

## 3. 構造（3層の下降＝Katabasis）

1. **静寂の森**（`silentForest` / B5F）— 地上に最も近い層。深淵の影響で音を失った森。
2. **暗黒城**（`darkCastle` / B8F）— かつて深淵を封じ損ねた者たちが眠る城の廃墟。
3. **深淵**（`abyss` / B10F）— 最深部。淀みの源＝ **深淵の主** がいる。

- 下るほど淀みは濃く、還らぬ者が増える。
- **目的 / エンディング**: 深淵を踏破し深淵の主を断つ → 淀みが鎮まり、地上に束の間の
  平穏が戻る。

## 4. 登場人物

- **村長（長老）**: かつての探索者。村を束ね、主人公を導く依頼主。オープニングで動機と
  世界を語り、各層の踏破ごとに次層の手がかりと物語を語る。深淵踏破でエンディングを見届ける。

## 5. トーン

やや厳かで寡黙。不思議のダンジョン風のゲーム性に、神話的な下降譚（Katabasis）の
陰翳を重ねる。台詞は短く、含みを持たせる。

## 6. 固有名詞

- 異形 / 淀みそのもの: **淀み（Miasma）**
- 最深部の元凶: **深淵の主**
- 拠点: 固有名を持たない「拠点の村」

## 7. 進行と台本（原典）

実データは [`game/story/index.ts`](../game/story/index.ts) を正とする。以下は原典。

### 7.1 オープニング（初回・拠点入場時に1回のみ）

> 地の底には「深淵」が口を開けている。
> かつてそこから這い出た"淀み"が、幾多の村と人を呑んだ。
> あなたの故郷も、その一つだった。
> ——奪われたものへ決着をつけるため、あなたは拠点の村の門をくぐる。
>
> 村長「…よく来た、探索者よ。その眼、深淵に何かを奪われた者の眼だ。」
> 村長「ここは深淵の唯一の入口を見張る村。深淵は塞げぬ——塞げば淀みは別の地から溢れる。」
> 村長「だから我らは下って鎮める。まずは静寂の森だ。音を失った、かつての緑の森。」
> 村長「淀みの源はさらに深く。…だが焦るな。一歩ずつ、下るのだ。」

### 7.2 村長の台詞（物語進捗＝踏破済みダンジョンに連動）

- **未踏破**: 静寂の森を目指すよう促す。
- **静寂の森 踏破後**: 暗黒城へ導く。
- **暗黒城 踏破後**: 深淵の核心（最深部）と深淵の主を警告する。
- **深淵 踏破後**: 主を断った者として遇し、なお尽きぬ淀みに触れる。

### 7.3 エンディング（深淵＝最終ダンジョン踏破時）

> 深淵の主は、断たれた。
> 淀みは鎮まり、地上に束の間の静けさが戻る。
> 奪われたものは、還らない。
> それでも——あなたは確かに、深淵を制したのだ。
>
> 村長「…よくぞ戻った。お前の故郷も、少しは安らかになろう。」
>
> だが深淵は、今日も静かに口を開けている。

## 8. 実装メモ

- オープニングは `meta.seenOpening`（localStorage 永続）で初回のみ表示。「はじめから」
  （`newGame()`）で false に戻る。
- 物語進捗は `meta.clearedDungeons`（踏破済みID配列）で管理。踏破は `finishSurvivedRun('cleared')`
  で記録。
- エンディングは踏破リザルト画面（`pages/gameover.vue`）で `lastRun.dungeonId === 'abyss'` の
  ときに表示する。
